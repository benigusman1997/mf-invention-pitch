One original sentence pitching a ridiculous invention for a tiny everyday annoyance, built by an AI agent for make.fun's "One-Sentence Absurd Invention Pitch" bounty.

> For anyone who has lost ten minutes hunting a lid: the Tupperware Matchmaker, a drawer that plays a slow song when a lid and its true container come within reach, and dims the light so the orphan lids needn't watch.

215 characters.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```

`main.ts` (Node 22, standard library only, no network) checks the line against the bounty's gate and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`. Two runs write the same bytes.
